# Distant Lands 0.2.0-alpha.1
2026-11-22

Hello all! The project has a new name, Distant Lands, and this release
brings it past the single all-Exile game: the Chronicle, the Empire and
Legacies are in, and every printed card power now runs.

## What's new

- **A new name.** Oath Digital is now Distant Lands. The Start files, the
  downloads and the save folder carry the new name.
- **The Chronicle.** Start a New Chronicle or continue a saved one, and play
  game after game with it. At the end of a game, the Chronicle Phase runs in
  the browser, and **Start Next Game** begins the next one. Chronicle Details,
  beside the Shared Bank, shows the Chronicle and the era's scorepad during
  a game.
- **The TTS mod's Chronicle format.** Import a Chronicle from the Tabletop
  Simulator mod, or export one to it (codec version 4).
- **The Empire.** Citizens and the Chancellor, Imperial sites, Citizenship
  offers, Shape Empire and the later-game setup.
- **Legacies.** Each player is dealt legacies at setup and keeps them as
  cards. Their Setup, in-play and Chronicle powers all run, and the winner's
  legacy bonus is scored in the Sun.
- **Every card.** All 255 denizens, 48 relics and 30 edifices are in.
- **More Negotiation.** Deals can now carry secrets, sites and advisers
  where a card allows it, promises are shown to every viewer, and Whispering
  Stone negotiates in private.
- **Consent.** A ruler sees the turn's requests and can change an answer
  until it is acted on.
- **The table.** The map is now one board with the real proportions of
  the cards and sites, and the Chronicle Phase has its own aid strip.
- **Starting on your own computer.** The Start file now opens your browser
  at `http://localhost:8080`. Players on other computers still use the
  address the window shows.

## Not in the game yet

- The end of an era: the Chronicle keeps going past the era's point target.
- Editing a saved Chronicle in the browser (the button is there, but
  disabled).
- The first-game option that ignores Citizenship powers.
- The Oathkeeper cards at Swear an Oath (the four goals are plain buttons).
- A summary of a Campaign's battle in the Game Log.

## Saved games

This is an alpha: **games saved by 0.1.0-alpha.4 or earlier won't load in
this release**, and games saved by this release may not load
in the next one. No release promises to open another release's saved games
yet.

With the new name, the Start file keeps its games in a new folder:

- **macOS**: `~/Library/Application Support/DistantLands/data`
- **Windows**: `%LOCALAPPDATA%\DistantLands\data`
- **Linux**: `~/.local/share/distantlands/data`

Your old `OathDigital` (or `oathdigital` on Linux) folder is left as it was.
Running an old release still opens the games in it, and you can delete it
when you no longer need them.

## Getting started

Download the archive below for your computer, extract it, then:

- **macOS**: double-click `Start Distant Lands.command`
- **Windows**: double-click `Start Distant Lands.bat`
- **Linux**: run `./start-distantlands.sh`

For the full walkthrough (dealing with security prompts, creating and
sharing your first game's seat links), see
[the quick start guide](https://github.com/eNamorD/distantlands/blob/v0.2.0-alpha.1/docs/operations/quick-start.md).

Each download below is checked against `SHA256SUMS`, also attached, if you'd
like to verify your copy.

## Known caveats

- Each player seat needs a separate browser profile: opening a second
  seat's link in the same browser silently kicks you out of the first. Use a
  different browser, or a separate profile/private window, for each seat you
  open yourself.
- The Chronicle page keeps your Chronicles in the browser you made them
  in, at the address you opened it with. Another browser, a private window
  or a different address (such as the LAN address instead of `localhost`)
  starts with an empty list. Use **Export Chronicle** to keep a copy you can import
  anywhere.
- A decision that a player never answers holds up the game: there are no
  timeouts.
- If your connection drops, reload the page to reconnect.
- Parts of Legacies' Chronicle Phase have only been checked by automated
  tests so far: a Public Ambitions row, the Chancellor's tie-break, and a
  player with more than three active legacies. Please report anything odd.
