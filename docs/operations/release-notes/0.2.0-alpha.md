# Distant Lands 0.2.0-alpha
2026-11-23

Hello Denizens...welcome to the Distant Lands!

As you can see, the app has a new name--and with it comes the vast
majority of the game's contents. I've been hard at work implementing
the Imperial, Chronicle and Legacies rules, which means it is now
actually possible to continue a Chronicle and play Oath as intended.
If testing goes well, Distant Lands will be ready to share publicly
within the next month!

Actually, I'm quite nervous about that, since I've never really launched a
webapp as a solo dev before (though I've been creating and developing
webapps for years now). There's still quite a lot of work ahead of me.
It's fine though. Mostly it's a fear of not knowing what I
don't know--I'm sure I'll rise to meet the challenges as they come up.
After all, if we're on a Quest to a Distant Land, there would be no sense of
adventure if I knew everything, right?

## What's new

- **Rename.** The Start files, downloads and the save folder have been renamed
  to match the project.
- **The Chronicle.** Start a New Chronicle or continue a saved one, and play
  game after game with it. At the end of a game, the Chronicle Phase runs in
  the browser, and **Start Next Game** begins the next one.
- **TTS Import and Export format.** Import a Chronicle from Tabletop
  Simulator, or export into the same format (codec version 4).
  Note: I don't think TTS currently has import implemented, but it's on the way.
- **The Empire.** Citizens and the Chancellor, Imperial sites, Citizenship
  offers, Shape Empire and the later-game setup.
- **Legacies.** Each player is dealt legacies at setup and keeps them as
  cards.
- **Every card.** All 255 denizens, 48 relics and 30 edifices are in.
- **More Negotiation.** Deals can now carry secrets, sites and advisers
  where a card allows it. Players can also make promises to each other.
- **Consent.** A power's ruler can now change their mind after giving or
  rejecting consent.
- **UX updates.** The map is now one board with the real proportions of
  the cards and sites.
- **Multiple seats in a browser.** You can now multi-hand a game within
  the same browser, instead of having to use incognito mode or a separate browser.

## Not in the game yet

- The end of an era: the Chronicle keeps going past the era's point target.
  If you want to reset your era, you'll have to edit the save file yourself.
- Editing a saved Chronicle in the browser (the button is there, but
  disabled).
- The first-game option that ignores Citizenship powers.
- Art assets from the real game.

## Saved games

This is an alpha: **games saved by 0.1.0-alpha.4 or earlier won't load in
this release.**

From this release on, the version number tells you whether your saves
survive an update. A release that changes only the last number, such as
0.2.1-alpha, loads the games and Chronicles saved by 0.2.0-alpha. A release
that changes the middle number, such as 0.3.0-alpha, may not.

With the new name, the Start file keeps its games in a new folder:

- **macOS**: `~/Library/Application Support/DistantLands/data`
- **Windows**: `%LOCALAPPDATA%\DistantLands\data`
- **Linux**: `~/.local/share/distantlands/data`

Your old `OathDigital` (or `oathdigital` on Linux) folder is left as it was.
Running an old release still opens the games in it, and you can delete it
when you no longer need them.

## Getting started

Download the archive below for your computer, extract it, then:

- **macOS**: double-click `Start Distant Lands.command`
- **Windows**: double-click `Start Distant Lands.bat`
- **Linux**: run `./start-distantlands.sh`

For the full walkthrough (dealing with security prompts, creating and
sharing your first game's seat links), see
[the quick start guide](https://github.com/eNamorD/distantlands/blob/v0.2.0-alpha/docs/operations/quick-start.md).

Each download below is checked against `SHA256SUMS`, also attached, if you'd
like to verify your copy.

## Known caveats

- The Chronicle page keeps your Chronicles in the browser you made them
  in, at the address you opened it with. Another browser, a private window
  or a different address (such as the LAN address instead of `localhost`)
  starts with an empty list. Use **Export Chronicle** to keep a copy you can use
  anywhere.
- If your connection drops, reload the page to reconnect.
- Parts of Legacies' Chronicle Phase have only been checked by automated
  tests so far: a Public Ambitions row, the Chancellor's tie-break, and a
  player with more than three active legacies. Please report anything odd.
