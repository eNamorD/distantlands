# Distant Lands 0.2.1-alpha
2026-11-27

This patch has a whole slew of fixes to cards, but more excitingly, it
adds an optional way for servers to use their own game art instead of
the default icons and card stand-ins!

## What's new

- **Game art.** A host who has art assets can point the server at a
  folder. Art assets include cards, the map, player pieces, tokens and
  dice. Each player can switch **Game art** on
  or off in the table's new Settings. Distant Lands ships no art; where a
  file is missing, the table keeps its own drawing for that card. See
  [game art](https://github.com/eNamorD/distantlands/blob/v0.2.1-alpha/docs/operations/game-art.md)
  for the folder's layout and how to set it in the Start file.
- **Vision Slot.** The Vision Slot has been made more visible.
- **Picking cards.** Search, the starting adviser and keeping a legacy now
  start with nothing picked for you. A pile whose order matters labels its
  end cards (Bottom and Top, or First and Last).
- **Short favor banks.** When a Trade asks for more favor than the bank
  holds, the log now says so, for example "Traded with Wrestlers for 3
  favor; but Order bank only had 1".
- **Tidier rows.** Card rows that wrap now split into even lines.
- **Black.** The Black player is now drawn in a slate grey,
  which reads better on the dark table.
- **Chronicle page.** Edit and Export Chronicle are hidden until a
  Chronicle is loaded.

## Card fixes

- Dowsing Sticks, Crystal Vial, Fearsome Shield, Black Sword, Demon Tail
  and Barbed Net now cost burnt favor, as printed, not secrets.
- Wine of Welcome now places a secret, Cracking Ground burns one, and
  Enchantress burns its secret instead of placing it.
- Unstable Summon is now a defender's battle plan; Disgraced Captain and
  Second Wind are attacker's plans. Keep is a plan the defender chooses in
  a Raid, rather than a rule that applies by itself.
- Threatening Roar stays when played to a site, and Relic Thief always
  rolls at least one die.
- Brass Horse lets the pawn stay at its own site, and Bandit Paymaster
  gains 2 warbands at a site bandits rule without removing a bandit.
- Several more cards now use the official card wording.

## Saved games

Games and Chronicles saved by 0.2.0-alpha load in this release. Games
saved by 0.1.0-alpha.4 or earlier still won't.

## Getting started

Download the archive below for your computer, extract it, then:

- **macOS**: double-click `Start Distant Lands.command`
- **Windows**: double-click `Start Distant Lands.bat`
- **Linux**: run `./start-distantlands.sh`

For the full walkthrough (dealing with security prompts, creating and
sharing your first game's seat links), see
[the quick start guide](https://github.com/eNamorD/distantlands/blob/v0.2.1-alpha/docs/operations/quick-start.md).

Each download below is checked against `SHA256SUMS`, also attached, if you'd
like to verify your copy.

## Known caveats

- The Chronicle page keeps your Chronicles in the browser you made them
  in, at the address you opened it with. Another browser, a private window
  or a different address (such as the LAN address instead of `localhost`)
  starts with an empty list. Use **Export Chronicle** to keep a copy you can use
  anywhere.
- If your connection drops, reload the page to reconnect.
- After the host replaces an art file, players may need a hard reload to
  see it: browsers keep an art file for a day.
- Parts of Legacies' Chronicle Phase have only been checked by automated
  tests so far: a Public Ambitions row, the Chancellor's tie-break, and a
  player with more than three active legacies. Please report anything odd.
